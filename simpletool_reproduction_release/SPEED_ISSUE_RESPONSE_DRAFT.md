Thanks for asking. We have added `simpletool_reproduction_release/` with recovered accuracy scripts, pinned model/data snapshots, complete v1 outputs, and a separate RTX 4090 W4A16-v2 latency benchmark. Please see `SPEED_BENCHMARK.md` and `reports/speed-4090/summary.md` for exact commands, environment compatibility, timing definitions, and raw measurements.

On the available RTX 4090 48 GB, repeated warm-cache median complete-call latencies were 31.2 ms (game), 58.3 ms (arm), and 41.4 ms (avatar). Resetting the prefix cache before every call gave 77.4, 93.0, and 88.9 ms. Each condition has 30 measurements per scenario. This is local vLLM latency for all function/argument heads, not HTTP latency, and the content head is omitted. These three short scenarios do not establish a workload-wide speedup factor; a matched autoregressive baseline has not been measured here.

We also document a compressed-tensors configuration compatibility issue with vLLM 0.11 and provide a separate metadata-only adaptation without changing weights. Full v2 BFCL accuracy has not been evaluated by this speed run. Training code is not part of this release; its publication schedule remains to be confirmed.
