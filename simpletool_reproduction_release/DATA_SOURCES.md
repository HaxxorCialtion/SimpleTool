# Benchmark sources

These files are byte-for-byte copies of the author's local
`benchmarks/Berkeley-Function-Calling-Leaderboard` fixtures, not refreshed upstream downloads.
`data/manifest.json` is the exact version/denominator contract for this reproduction.

| Local files | Source family |
| --- | --- |
| BFCL_v3_* | Berkeley Function Calling Leaderboard: https://github.com/ShishirPatil/gorilla/tree/main/berkeley-function-call-leaderboard |
| sealtools_test_* | Seal-Tools; local preparation under `benchmarks/sealtools/Seal-Tools` |
| openfunctions_v1_test | OpenFunctions v1; local processed fixtures under `openfunctions_processed` |
| toolalpaca_test_*_converted | ToolAlpaca; local preparation under `benchmarks/toolAlpaca/ToolAlpaca` |
| mobile_actions | Author's local Mobile Actions fixture |

The local BFCL dataset README declares Apache-2.0; its original text is preserved
in `data/BFCL_UPSTREAM_README.md`. Other local upstream README/license files, when present,
are retained under `data/source_notices/`. These source notices do not assert a new
blanket license over the combined transformed dataset.
